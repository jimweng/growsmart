# GrowSmart 商業化規劃書

> 目標：透過三個階段實現自由現金流為正，無需外部資金即可持續運轉。

---

## 市場機會

- 育兒 App 全球市場 2025 年估值 **USD 17.2 億**，2035 年預估 **USD 49.1 億**（CAGR 11.4%）
- 亞洲兒童保健品市場 2033 年估值 **USD 90 億**（CAGR 7.44%）
- 台灣家長對兒童成長焦慮高，付費意願強於歐美市場

## Phase A：聯盟行銷（低開發成本，快速變現）

### 核心邏輯

GrowSmart 已知每個孩子的**年齡、性別、身高百分位、體重**，具備市場上最精準的推薦時機。

### 推薦觸發條件與產品

| 觸發條件 | 推薦商品 | 平均佣金率 |
|---------|---------|-----------|
| 身高 P < 25 | 鈣片、維生素 D3、鋅補充品 | 5–15% |
| 體重偏低（P < 15） | 高蛋白補充品、兒童配方奶 | 5–10% |
| 0–24 個月 | 嬰兒配方奶（Abbott、Mead Johnson、Nestlé） | 8–12% |
| 全年齡 | 成長奶粉、乳鈣、Omega-3 | 5–10% |
| 就醫提醒觸發（P < 3） | 兒科診所導流 | 導流費 per booking |

### 實作方式

在現有的**追趕生長營養建議卡**（P ≤ 15）加入「推薦商品」按鈕，帶聯盟連結至 momo 購物、蝦皮、或品牌官網。
在**就醫評估清單**（P < 3）加入「附近診所」按鈕，對接 iClinics 或 MedBridge 預約 API。

### 預估收入（月）

假設 MAU 1,000 人，觸發率 30%，平均客單價 NT$800，佣金 8%：
> **月收入 ≈ NT$1,920**（初期，持續增長）

## Phase B：Freemium → Premium 訂閱（核心商業模式）

### 訂閱方案設計

| 功能 | 免費版 | Premium（NT$99/月）|
|-----|------|-----------------|
| 追蹤孩子數量 | 1 位 | 無限制 |
| WHO 成長曲線 | ✅ | ✅ |
| 百分位計算 | ✅ | ✅ |
| AI 成長顧問 | 5 次/月 | 無限次 |
| **PDF 成長報告** | ❌ | ✅ |
| **成長提醒推播** | ❌ | ✅ |
| **歷史資料完整匯出** | ❌ | ✅ |
| **個人化營養計算** | 基礎版 | 含食譜建議 |

### 為什麼 PDF 報告是關鍵付費點

家長看診前最需要一份**整理好的成長記錄**給兒科醫師。GrowSmart 已有所有數據，生成 PDF 只需前端渲染，邊際成本接近零，但對家長有明確使用場景 → **付費意願最強**。

### 預估收入（月）

假設 MAU 5,000 人，Premium 轉換率 5%，NT$99/月：
> **月收入 ≈ NT$24,750**

## Phase C：診所/品牌合作（規模化）

### 兒科診所白標方案

- 提供診所客製化版本（診所 logo + 顏色）
- 診所付月費 NT$2,000–5,000/間，換取患者成長記錄整合
- 目標：台灣共有約 1,500 家小兒科診所

### 保健品品牌贊助內容

- 「生長三元素」生活指南卡中的特定建議由品牌贊助
- 例：「鈣質補充建議：X 品牌乳鈣（贊助）」
- 月費：NT$10,000–30,000/品牌

### 匿名數據授權

- 台灣兒童成長趨勢匿名數據授權給學術機構或保健品公司做研究
- 需明確用戶同意（opt-in）
- 單次授權費：NT$50,000–200,000

## 優先開發路線

```
現在可做（不需新開發）
  → 在 catch-up nutrition card 加聯盟商品連結
  → 收集 email 名單（未來訂閱轉換用）

第一季
  → PDF 成長報告生成（jsPDF 或後端渲染）
  → Premium 訂閱牆（Stripe 或 ECPay）
  → 推播通知（測量提醒、成長警示）

第二季
  → 診所合作 API 整合
  → 品牌贊助內容系統
```

## 競爭優勢

1. **精準觸發**：比一般育兒 App 更了解孩子的成長狀態，推薦時機精準
2. **醫學可信度**：基於 WHO LMS 標準，不是模糊建議
3. **台灣在地化**：中文介面 + 台灣家長痛點（追趕生長焦慮）
4. **低邊際成本**：數據計算 + AI 建議的邊際成本接近零，規模化容易
